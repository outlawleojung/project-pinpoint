# 화면 정의서 (Screen Specification) — Pinpoint SEO Linter (v1)

> **문서 목적**: Pinpoint SEO Linter (v1) MVP의 웹 UI 화면 구조, 컴포넌트 명세, 사용자 인터랙션 및 바인딩 데이터를 정의하여 프론트엔드 개발의 기준점으로 삼는다.
> **최종 업데이트**: 2026-08-10
> **상태**: 초안 작성 (오너 검토 대기)

---

## 1. UI 디자인 시스템 가이드라인 (Aesthetics & Tokens)

- **테마**: sleek dark mode (다크 그레이 `#121212` 및 `#1E1E1E` 백그라운드)
- **포인트 컬러**: 네온 그린 (`#10B981`, 정상/성공) & 크림슨 레드 (`#EF4444`, 감점/경고)
- **글꼴**: Inter / Outfit (Clean Sans-serif 계열)
- **레이아웃**: 좌측 글로벌 네비게이션 바(LNB) + 메인 콘텐츠 대시보드 영역

---

## 2. 화면 목록 (Screen List)

| 화면 ID | 화면명 | 주요 목적 | 주요 사용자 액션 |

## 3. 화면별 상세 명세 (Screen Specifications)

### SCR-101: 스토어 API 연동 화면 (Store Integration)

#### [화면 구조 와이어프레임]
```text
+--------------------------------------------------------------+
|                      Project Pinpoint 🎯                     |
|                                                              |
|                  스마트스토어 API 연동                       |
|   서비스를 시작하려면 네이버 커머스 API 정보를 입력해 주세요.   |
|   (Read-only 권한만으로 작동하며 스토어 데이터를 변경하지 않습니다.)|
|                                                              |
|   +------------------------------------------------------+   |
|   | Client ID:     [ _________________________________ ] |   |
|   | Client Secret: [ _________________________________ ] |   |
|   +------------------------------------------------------+   |
|                                                              |
|                     [ 스토어 연동 및 분석 시작 ]             |
+--------------------------------------------------------------+
```

#### [컴포넌트 및 인터랙션 명세]
- **API Key 입력 폼**:
  - `Client ID` 및 `Client Secret` 입력 텍스트 필드 (가이드 플레이스홀더 제공).
- **연동 및 분석 시작 버튼**:
  - 클릭 시 백엔드 API `/api/v1/store/verify`를 호출하여 Key 유효성을 1차 검증.
  - 유효할 경우, 스피너 로딩 UI와 함께 비동기 상품 수집 및 린팅 큐를 구동하고 SCR-102(대시보드)로 자동 전환.
  - 유효하지 않을 경우, 폼 하단에 크림슨 레드 컬러로 `[에러: API 정보가 일치하지 않거나 권한이 유효하지 않습니다]` 텍스트 노출.

### SCR-102: 종합 진단 대시보드 (Store Dashboard)

#### [화면 구조 와이어프레임]
```text
+--------------------------------------------------------------+
| LNB  |  [스토어명] 스마트스토어 SEO 대시보드                  |
|      |  --------------------------------------------------   |
| 홈   |  +-------------------+  +--------------------------+  |
|      |  | 스토어 SEO 건강 점수|  |   상태 요약 카드          |  |
| 분석 |  |       [ 78점 ]    |  |   - 총 상품수: 320개      |  |
|      |  |     (원형 게이지)  |  |   - 정상 상품: 215개      |  |
| 설정 |  |                   |  |   - 감점 의심: 105개 [이동]|  |
|      |  +-------------------+  +--------------------------+  |
|      |                                                       |
|      |  +-------------------------------------------------+  |
|      |  |             위반 유형별 분포 차트               |  |
|      |  |  명사 중복:   ███████████████ 45개 (43%)        |  |
|      |  |  비권장 부호: ██████████ 30개 (28%)              |  |
|      |  |  글자수 초과: ██████ 18개 (17%)                  |  |
|      |  |  카테 불매칭: ████ 12개 (12%)                    |  |
|      |  +-------------------------------------------------+  |
+--------------------------------------------------------------+
```

#### [컴포넌트 및 인터랙션 명세]
- **건강 점수 게이지 (Gauge Chart)**:
  - 100점 만점 기준의 가중치 평균 점수 시각화. 90점 이상은 네온 그린, 60~89점은 엘로우, 59점 이하는 크림슨 레드로 게이지 바 컬러 동적 변화.
- **감점 의심 상품 [이동] 링크 버튼**:
  - 클릭 시 SCR-103(상세 진단 화면)으로 이동하며 자동으로 `감점 상품 필터`가 활성화된 채로 랜더링.
- **유형별 분포 차트 (Horizontal Bar Chart)**:
  - 린팅 규칙(F-102)별 검출 빈도를 바 형태로 시각화하여 사용자가 스토어의 주요 취약 지점을 한눈에 확인 가능.

### SCR-103: 상품별 상세 진단 및 교정 화면 (Scan Detail)

#### [화면 구조 와이어프레임]
```text
+-----------------------------------------------------------------------+
| LNB  |  상세 진단 및 교정                                             |
|      |  [전체보기] [감점의심만 보기]   [검색: ______________________] |
| 홈   |  ------------------------------------------------------------- |
|      |  이미지 | 상품명                  | 카테고리 | 감점 요인       | 액션  |
| 분석 |  -------+-------------------------+----------+-----------------+------ |
|      |  [IMG]  | 컴퓨터의자 게이밍의자   | 가구/의자| 명사중복, 글자수| [진단]|
| 설정 |  [IMG]  | 친환경 오가닉 코튼 양말 | 패션/의류| 정상            | [진단]|
|      |                                                                        |
|      |  +------------------------------------------------------------------+  |
|      |  | [상세 모달] 컴퓨터의자 게이밍의자                                  |  |
|      |  |  ● 검출된 감점 요인:                                               |  |
|      |  |    - '의자' 명사 2회 중복 사용 (네이버 로직 3회 이상 중복 기준 경고) |  |
|      |  |  ● 추천 교정 상품명:                                               |  |
|      |  |    [ 에르고 가죽 게이밍 컴퓨터 의자                 ] [1클릭 복사]  |  |
|      |  |  ● 추천 키워드 후보:                                               |  |
|      |  |    #목편한의자 #게이밍의자추천 #인체공학체어                       |  |
|      |  +------------------------------------------------------------------+  |
+-----------------------------------------------------------------------+
```

#### [컴포넌트 및 인터랙션 명세]
- **상품 필터 탭 & 검색창**:
  - `전체보기`와 `감점의심만 보기` 토글 탭 제공. 상품명 키워드로 검색이 가능한 실시간 인풋 필터 탑재.
- **상세 진단 모달/드로어**:
  - 각 행의 `[진단]` 버튼 클릭 시 화면 우측 또는 중앙에 슬라이드-인 드로어 활성화.
  - 진단 세부 사유와 함께 백엔드 알고리즘(F-103)이 제안한 **교정 상품명 텍스트 필드** 렌더링.
- **1클릭 복사 버튼 (Copy-to-Clipboard)**:
  - 교정 상품명 옆의 복사 버튼 클릭 시 OS 클립보드에 제안된 상품명이 복사되며, `[복사 완료]` 토스트 팝업이 2초간 화면 상단에 플로팅.
  - 셀러는 이를 활용하여 스마트스토어센터 탭으로 이동해 즉시 붙여넣기(Ctrl+V) 수정 가능.
- **추천 키워드 태그 클릭**:
  - 각 추천 키워드 태그 클릭 시 해당 키워드 텍스트가 클립보드에 즉시 복사되어 태그 정보 수정에 신속히 활용 가능하도록 지원.
