# Fact Sheet 01: 이커머스 CS 자동 응대 Micro-B2B SaaS

> **문서 목적**: Project Pinpoint의 후보 영역 #1인 **CS 자동 응대** 시장에 대해 검증된 데이터 기반 분석 및 팩트 조사를 기록한다.
> **최종 업데이트**: 2026-08-09
> **상태**: Phase 2 팩트시트 작성 완료 (우선순위 판정 대기)

---

## 1. 개요 (Executive Summary)

- **핵심 문제**: 셀러가 매일 반복하는 배송/주문/반품/상품 문의가 전체 CS의 **70%**를 차지하며, 매출 연관 작업(소싱/마케팅)을 마비시킴.
- **시장 기회**: 기존 대형 솔루션(채널톡, 해피톡)은 **월 20~50만 원대의 높은 비용**과 **복잡한 시나리오 설계**를 요구함. 1인 및 소규모 셀러(월 매출 1천만~5천만 원)를 위한 **API 1클릭 연동 + 초저가/초간단 특화 SaaS** 공백 존재.
- **판정 결론**: **[고득점 추진 후보]** — 네이버 스마트스토어/쿠팡 API 연동 난이도는 있으나, 백엔드 엔지니어링 역량을 활용해 확실한 진입장벽 구축 가능.

## 3. 셀러의 실제 비용 및 시간 소모량

### 3.1 시간 소모량

- **일평균 CS 처리 시간**: 1인 셀러 기준 **하루 평균 2.5시간** 소모 (이커머스 셀러 커뮤니티 설문 및 런모아AI 분석 데이터 기준).
- **피크 타임**: 오전 9~11시(송장 배송 문의), 오후 5~7시(취소/교환 문의), **주말/야간 문의 누적**.
- **업무 마비 현상**: CS 답변 때문에 소싱, 상세페이지 작성, 광고 관리가 계속 중단됨 (Context Switching 비용 심각).

### 3.2 비용 소모량

- **CS 아웃소싱/알바 고용**: Part-time CS 알바 월 80만~120만 원 / 정직원 채용 시 **월 250만 원**(4대보험 포함).
- **외주 건당 비용**: 건당 1,000원 ~ 1,500원 (CS 대행 업체 과금 기준).
- **단순 반복 문의 비율**: **전체 문의의 70%** (배송 현황, 송장 번호, 취소 절차, 간단 스펙 / 런모아AI 데이터 기준).

## 4. TAM (Total Addressable Market) 산정

```text
[TAM - 전체 시장]
국내 이커머스 실질 액티브 셀러 약 30만 명 (통신판매업 신고 기준 스마트스토어/쿠팡 중복 제거 활성 판매자 추정치)
→ 30만 명 × 월 5만 원 ($39) × 12개월 = 연 1,800억 원

[SAM - 유효 시장]
월 매출 1천만 ~ 5천만 원 사이 중소형 셀러 (전체의 약 20%) = 6만 명
→ 6만 명 × 월 5만 원 × 12개월 = 연 360억 원

[SOM - 목표 시장 (Micro-B2B SaaS)]
초기 목표 셀러 500명 (월 구독 전환)
→ 500명 × 월 5만 원 ($38) = MRR 2,500만 원 ($19K MRR)
```

> [!NOTE]
> **SOM 현실성 및 포트폴리오 전략 주석**: 본 SOM은 4개 SaaS 제품을 동시 운영하여 매출을 단순 합산하는 구조가 아닙니다. 이는 **개별 MVP가 PMF(제품-시장 적합성)를 확보했다고 판단하여 스케일업을 결정할 수 있는 단독 기준점**입니다. 1인 개발자의 리소스 제약을 감안하여 포트폴리오 검증 과정 중 1개 제품이라도 본 SOM($19K MRR)에 먼저 도달하면, 나머지 후보군은 즉시 아카이빙(보류)하고 해당 우승 제품에 리소스를 100% 집중하여 확장하는 린(Lean) 스케일업 전략을 실행합니다.

## 5. 기존 도구의 가격대 및 핵심 페인포인트

### 5.1 기존 도구 가격 구조

- **채널톡 / 해피톡**: 기본료 + 세션/상담 건수당 과금 구조. 문의량이 급증하면 월 요금이 30~50만 원 이상으로 튐.

### 5.2 셀러들의 핵심 페인포인트 (커뮤니티 및 현장 피드백)

1. **"세팅이 너무 어렵다"**: 시나리오 트리(Tree)를 셀러가 직접 블록 조립하듯 맞춰야 함 (설치 후 포기율 50% 이상).
2. **"마켓 연동 불완전"**: 네이버 톡톡, 쿠팡 문의, 카카오톡 상담이 분산되어 있어 한 곳에서 실시간 송장 조회/자동 답변이 안 됨.
3. **"야간/주말 문의 대응 불가"**: 퇴근 후나 주말에 들어오는 단순 문의에 즉시 답변하지 못해 **고객 취소율 증가 및 네이버 톡톡 응대율 점수 감점**.
4. **"비용 부담"**: 월 10~20만 원 이상 내기엔 소형 셀러에게 매달 고정비 부담이 큼.

## 6. Project Pinpoint +1 차별화 전략 (Hookable Formula)

```text
[통합 솔루션 (채널톡/해피톡)]
"고객 상담, CRM 마케팅, 팀 채팅, 시나리오 챗봇 다 제공합니다. (월 15~30만원)"

                    ▼ (Hookable +1 차별화)

[Pinpoint CS Agent]
"설정 0초. 네이버/쿠팡 연동만 하면 야간/주말 배송·반품 문의를 AI가 송장번호 조회해서 100% 자동 답변해 드립니다. (월 $39 단일가)"
```

### 핵심 +1 차별화 요소 3가지

1. **Zero-Setup AI (학습/시나리오 작성 제로)**:
   - 셀러의 상품 페이지, 배송 정책, 공지사항을 URL 하나로 자동 긁어와 AI RAG(검색증강생성)로 즉시 학습.
2. **실시간 송장/주문 DB 조회 연동**:
   - 스마트스토어/쿠팡 API 연동으로 "내 물건 어디서 오는가?" 문의에 **실시간 택배사 배송 상태를 조회하여 답변**.
3. **정액제 요금 (월 $39~$69)**:
   - 건수 초과 과금 없이 단순 반복 문의 무제한 방어 (주말/야간 응대율 100% 보장).

## 7. 백엔드 엔지니어링 구현 포인트

- **API Rate Limit 및 OAuth 관리**: 스마트스토어 API, 쿠팡 Open API, 네이버 톡톡 파트너 API 간 인증 토큰 관리 및 호출 제한 회피 Queue 설계 (Redis + BullMQ).
- **비동기 RAG 파이프라인**: 상품 정보 변경 시 비동기로 Embedding 및 Vector DB(Pgvector/Qdrant) 업데이트.
- **할루시네이션(환각) 방지**: 주문/배송 데이터는 LLM 추론이 아닌 DB Direct Fetch 후 Template Injection으로 100% 정확도 보장.

## 8. 성공/실패 검증 지표 (Validation Metric)

- **MVP 개발 기간**: 2주
- **초기 검증 목표**:
  - 랜딩페이지 가입 셀러 50명 확보 (2주)
  - 베타테스트 진행 후 **유료 전환 셀러 10명** (월 4.9만 원 / MRR ~50만 원)
- **성공 판단 기준**: 3개월 내 유료 회원 50명 달성 ($2K MRR) → 스케일업 및 고도화.
