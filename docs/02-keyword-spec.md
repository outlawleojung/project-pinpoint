# 기능 정의서 (Functional Specification) — Pinpoint SEO Linter (v1)

> **문서 목적**: 첫 번째 MVP 제품인 **Pinpoint SEO Linter (v1)**의 사용자 시나리오, 구체적 기능 범위, 시스템 요구사항을 정의하여 설계 및 개발의 기준점으로 삼는다.
> **최종 업데이트**: 2026-08-10
> **상태**: 초안 작성 (오너 검토 대기)

---

## 1. 제품 개요 및 핵심 가치 (Value Proposition)

- **제품명**: Pinpoint SEO Linter (v1)
- **한 줄 요약**: 네이버 스마트스토어 API 연동을 통해, 내 스토어 전체 상품의 상품명/태그 내 노출 감점 요소를 3초 만에 스캔하여 정밀 교정안을 제공하는 **Read-only 진단 솔루션**.
- **핵심 가치**: 
  - **Zero Risk**: 상품명 강제 수정이나 CS 봇 오답 리스크 없이, 오직 진단과 제안만 수행하므로 셀러 평판 훼손 위험 0%.
  - **보안 장벽 최소화**: 쓰기(Write) 권한 없이 **읽기(Read) 권한만으로 연동**하여 개인정보 및 스토어 권한 남용 우려 해소.
  - **즉각적인 가치 증명**: 연동 즉시 "전체 상품 중 감점 상품 X개"를 시각화하여 사용자가 서비스의 필요성을 즉각 체감.

## 2. 사용자 여정 (User Flow)

```text
[Step 1: 마켓 API 연동] 
  ➡️ 셀러가 네이버 커머스 API Center에서 발급받은 Read-only API Key 입력
[Step 2: 상품 동기화 및 진단 실행] 
  ➡️ API를 통해 스토어의 상품 목록을 조회하고, 백엔드 Linter 엔진이 실시간 진단 수행
[Step 3: 대시보드 리포트 확인] 
  ➡️ 전체 상품의 'SEO 건강도 점수'와 노출 로직 위반 상태(감점 의심 상품 수) 시각화 확인
[Step 4: 상품별 상세 진단 및 교정] 
  ➡️ 감점 상품 목록 선택 ➡️ 감점 요인(중복, 글자수, 카테고리 불매칭) 확인 
  ➡️ AI/알고리즘 교정 상품명 및 추천 키워드 확인 ➡️ 1-Click 클립보드 복사
```

## 3. 핵심 기능 명세 (Functional Requirements)

### F-101: 스마트스토어 상품 연동 모듈 (Read-only Sync)
- **기능 설명**: 네이버 커머스 API를 호출하여 판매자의 활성 상품 리스트를 가져오는 모듈.
- **상세 요구사항**:
  - API Client ID 및 Client Secret 검증.
  - 현재 판매 중(SALE) 및 전시 중인 상품 정보(상품 ID, 상품명, 카테고리 ID, 판매자 태그, 상세페이지 URL) 동기화.
  - 대량 상품 조회를 위해 API 페이지네이션(Pagination) 처리 및 속도 제어(Rate Limit 방지).

### F-102: 실시간 SEO Linter (진단) 규칙 엔진
- **기능 설명**: 네이버 쇼핑 공식 상품 등록 가이드라인을 기반으로 상품명의 노출 감점 요소를 분석하는 엔진.
- **진단 규칙(Ruleset)**:
  1. **명사 중복 검출 (형태소 분석)**:
     - 한국어 형태소 분석기(Mecab)를 활용하여 상품명에서 명사를 추출.
     - 동일 단어(동음이의어 포함)가 3회 이상 반복 사용될 경우 '키워드 도배(감점 요인)' 경고 및 감점 점수 차감.
  2. **금지 문자 및 특수문자 필터링**:
     - 네이버가 권장하지 않는 특수문자(예: `[], (), {}, @, *, ★, 묶음` 등 공식 가이드 외 기호) 포함 여부 판독 및 경고.
  3. **권장 글자 수 검증**:
     - 전체 상품명 글자 수가 네이버 최적 노출 권장 기준(25자 이상 ~ 50자 이하)을 초과하거나 지나치게 짧은 경우 경고.
  4. **카테고리 매칭 유효성 체크**:
     - 상품이 등록된 표준 카테고리 메타데이터와 상품명 내 추출 명사들의 연관성을 체크하여 불일치 시 노출 제외 위험 경고 (로컬 카테고리-키워드 사전 맵 기준 검사).

### F-103: 키워드 정제 및 추천 엔진 (Optimizer)
- **기능 설명**: 감점 요인을 배제하고 노출 효율을 극대화하는 정정 상품명을 구성하여 제안하는 엔진.
- **상세 요구사항**:
  - 형태소 분석 결과 중복된 키워드를 제거하고 브랜드, 모델명, 핵심 키워드를 최적의 가이드라인 순서(네이버 권장 가이드: `브랜드 + 제조사 + 시리즈 + 상품명 + 모델명 + 색상/속성`)로 재조합한 교정안 제안.
  - 검색량 분석 API(또는 로컬 키워드 캐시)를 참고하여 상품 카테고리와 매칭률이 높은 실시간 유입 키워드 후보 3개 추천.

### F-104: 대시보드 및 리포트 UI (Dashboard)
- **기능 설명**: 스토어의 SEO 상태를 직관적으로 요약하고 교정을 지원하는 웹 화면.
- **화면 구성**:
  - **스토어 종합 점수**: 100점 만점 기준의 SEO 적합도 점수 시각화.
  - **진단 통계**: `정상 상품 수` vs `감점 의심 상품 수` 및 위반 유형별(중복 단어, 특수문자, 카테고리 불매칭) 분포 차트.
  - **상품별 진단 테이블**: 감점 상품 필터링 정렬 기능, 각 상품 행 선택 시 우측 또는 하단에 상세 진단서(위반 단어 표기 및 교정 제안 상품명, 1-Click 클립보드 복사 버튼) 제공.

## 4. v1 제외 범위 (Out of Scope for v1)

2주 내 MVP 출시와 안전한 검증을 위해 아래 기능은 v1 스코프에서 배제하며, 추후 고도화 버전(v2)으로 이관한다.
- **마켓 직접 수정 반영 (API Write)**: API를 통해 네이버 스마트스토어의 상품 정보를 실제 변경하는 쓰기 트랜잭션. (v1은 복사-붙여넣기 형태의 Linter로 작동)
- **쿠팡 윙(Wing) 마켓 연동**: 쿠팡 상품 정보 연동 및 쿠팡 알고리즘용 Linter 구축. (v1은 네이버 스마트스토어에 집중)
- **실시간 검색 순위 추적 (SERP Tracker)**: 특정 키워드로 검색했을 때 내 상품의 실시간 순위를 크롤링해 오는 기능.
- **순위 변화에 따른 자동 리프레시 크론 잡**: 검색량 순위에 따라 백그라운드에서 키워드를 자동 최적화하는 데몬.
